What to have ready

Having these on hand turns a two-call question into a one-call answer.

  • Your account or company name — pricing is set per account, so we need to know whose it is.
  • Style number — the four digits from the product page, like 1301 or 5230.
  • Color name and the size breakdown you want, with quantities.
  • Invoice or order number if you are calling about something that already shipped.
  • Photos if something arrived short, damaged or wrong.
